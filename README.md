# 企业劳动人事高频 100 问 · 自助咨询小程序
**Enterprise Labor & Employment FAQ 100 · Self-Service Q&A Mini Program**

面向园区企业的劳动人事高频问题自助查询工具。以《企业劳动人事高频 100 问》问答内容为底座，在微信内提供分类浏览、关键词检索与问答匹配。

A self-service reference tool for enterprises: browse, search and match answers to 100 frequently asked labor & employment questions, delivered as a WeChat mini program.

## 当前状态 / Status

仓库处于初始化阶段：已完成项目说明与开源协议，100 问数据集与小程序代码将在后续提交。下述目录为规划结构，尚未全部落地。

This repository is at initialization stage. The FAQ dataset and the mini program code are not committed yet; the structure below is planned, not yet implemented.

## 内容口径 / Content Basis

- 问答内容依据公开的法律法规、司法解释及实务常见问题整理，仅供一般性参考。
- 同一问题在不同地区、不同事实条件下结论可能不同；答案不替代针对具体事项的专业判断。
- 内容随法规更新而修订，请以仓库最新版本为准。

Q&A entries are compiled from publicly available laws, regulations and common practice questions for general reference only. Answers may vary by jurisdiction and facts, and do not replace advice on a specific matter.
